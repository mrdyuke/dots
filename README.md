# Personal Dotfiles

## Overview

This is a personal repository for storing and version-controlling base configuration files (dotfiles). 

This is not a polished, ready-to-use framework for the general public. These configs are working files for personal use, tailored to a specific workflow and hardware setup. Some snippets, including animations, were taken from other open-source projects; the author does not claim ownership of those parts.

## Supported Distributions

Configs are organized by distribution/setup:

- **Arch** (`arch/`) - Configuration files for Arch Linux
- **Omarchy** (`omarchy/`) - Configuration files for an Omarchy-based setup

Other configurations may be adapted for Debian/Ubuntu and Fedora as needed, but there is no guarantee of completeness or compatibility across distributions.
